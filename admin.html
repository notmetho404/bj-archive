GitHub 연결

연결하면 저장 버튼 한 번으로 데이터와 사진이 저장소에 올라가요. 입력한 값은 이 브라우저(localStorage)에만 저장돼요. 공용 컴퓨터에서는 쓰지 마세요.

  1. 토큰 만들기 페이지를 열어요.
  2. Repository access → Only select repositories → 이 저장소 하나만 선택해요.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Generate token을 누르고 나온 값을 위 칸에 붙여 넣어요.
